
# RAADI – رَادي

منصة إلكترونية للإعلانات والسوق المحلي في الصومال.

## فكرة المشروع

تربط منصة RAADI البائعين بالمشترين، وتساعد الأشخاص على عرض أجهزتهم المستعملة وأراضيهم للبيع، والعثور على المنتجات حسب المدينة والفئة.

## الفئات

- الهواتف المستعملة.
- الحواسيب.
- الأجهزة الإلكترونية الأخرى.
- الأراضي الخام غير المبنية.

## طريقة العمل

1. يضيف البائع إعلانًا مع الصور والسعر والموقع.
2. تراجع الإدارة الإعلان وتوافق عليه.
3. يظهر الإعلان للمشترين.
4. يتواصل المشتري مع البائع مباشرة عبر واتساب.

## نموذج الإيرادات

تبدأ المنصة بإعلانات مجانية خلال أول شهر أو شهرين.

بعد فترة الإطلاق، تُفرض رسوم على الإعلان قبل نشره. الرسوم المقترحة هي 1 أو 3 أو 5 دولارات، ويُحدد السعر النهائي لاحقًا.

لا تتولى المنصة دفع ثمن السلعة أو التوصيل أو حل النزاعات بين البائع والمشتري.
